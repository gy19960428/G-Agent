# WMS 微信小程序扫码端

原生微信小程序基线，用于仓库现场扫码查询箱号、确认出货、登记退回复检。

## 导入开发者工具

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择 `wms_fullstack/miniprogram`。
4. AppID 可先选择测试号或使用 `touristappid` 调试。
5. 本机开发阶段已在 `project.config.json` 关闭 URL 校验，便于访问本机 HTTP API。

## 后端地址配置

默认配置在 `app.js`：

```js
apiBase: 'http://127.0.0.1:5000/api'
```

- 开发者工具运行在电脑上时，可用 `127.0.0.1`。
- 真机预览/调试时，手机上的 `127.0.0.1` 指手机自身，必须改成电脑局域网 IP，例如：

```js
apiBase: 'http://192.168.50.88:5000/api'
```

同时确认电脑和手机在同一局域网，后端监听 `0.0.0.0:5000`，防火墙允许访问 5000 端口。

## 页面能力

- 首页：扫码、手工输入箱号、查看库存/出货概况。
- 箱号详情页：查询产品、订单、数量、状态、装箱/出货/退回时间。
- 操作：库存箱确认出货，已出货箱登记退回复检。

## 微信内部试用方式

本项目优先按公司内部工具使用，不需要公开上架微信小程序商店。

### 开发阶段

1. 用微信开发者工具导入 `wms_fullstack/miniprogram`。
2. `app.js` 里的 `apiBase` 指向当前后端地址。
3. 点击“预览”，用仓库员工手机微信扫码临时体验。
4. 本机 HTTP 调试阶段，需要在开发者工具勾选“不校验合法域名、web-view、TLS 版本以及 HTTPS 证书”。

### 公司内部体验版

1. 到微信公众平台创建/绑定小程序 AppID。
2. 在“成员管理”中添加仓库、质检、发货人员为项目成员或体验成员。
3. 开发者工具中使用正式 AppID 上传代码。
4. 微信公众平台选择该版本为“体验版”。
5. 内部成员从微信收到的体验版入口打开即可使用。

### 生产使用建议

- 内部长期使用也建议走体验版或开发版，不做公开发布。
- 真机连接公司服务器时，`apiBase` 必须改成服务器 HTTPS 地址，例如 `https://你的域名/api`。
- 如果暂时只在公司局域网试用，可使用电脑局域网 IP，但微信正式体验环境通常会限制 HTTP 和非法域名。

## 正式发布前

如以后决定公开发布，微信正式版要求 HTTPS 和 request 合法域名：

1. 公司服务器部署后端 API。
2. 配置正式域名和 HTTPS 证书。
3. 小程序后台添加 `https://你的域名` 到 request 合法域名。
4. 将 `app.js` 的 `apiBase` 改成 `https://你的域名/api`。
5. 重新上传体验版并真机验收扫码、出货、退回流程。
